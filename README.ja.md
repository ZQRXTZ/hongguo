# 紅果ショートドラマ収集 · hongguo

紅果（Hongguo）のショートドラマ収集プロジェクトです。デバイス登録、動画のダウンロードとトランスコード、保存先フォルダー、エピソード別ファイル、ローカル再生の例を紹介します。

## 機能と概要

- **デバイス登録**：登録時に返されるデバイス ID やインストール ID などの情報を表示します。
- **ダウンロードと変換の進捗**：ダウンロード数、変換完了数、待機中・変換中・失敗したタスク数を確認できます。
- **作品別のフォルダー管理**：「作品名 + ID」でフォルダーを分け、検索や整理をしやすくします。
- **エピソード別の保存**：話数順に動画を保存します。画像内のファイル名の例は `001_1080p.mp4` です。
- **再生例**：実写ドラマとアニメーションのローカル再生画面を紹介します。

## スクリーンショット

### 1. デバイス登録と動画ダウンロード

デバイス登録の応答と、ダウンロード・変換タスクの進捗です。撮影時点ではダウンロードが `127/222`、変換完了が `118/222`、待機中が `8`、変換中が `1`、失敗が `0` でした。

![デバイス登録の応答とダウンロード・変換の進捗](./device_register.png)

### 2. ダウンロードした作品のフォルダー

作品ごとに専用フォルダーへ保存します。フォルダー名には作品名と ID が含まれ、識別や整理が容易です。

![ダウンロードした作品のフォルダー一覧](./videos_name.png)

### 3. エピソード別ファイル

各作品のフォルダー内では、動画が話数順に並びます。以下は《持械入宋：第一季》の例で、`001_1080p.mp4`、`002_1080p.mp4` などのファイルとサムネイルを表示しています。

![話数順に並ぶ動画ファイルとサムネイル](./video_parts.jpg)
