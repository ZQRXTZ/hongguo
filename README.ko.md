# 홍궈 숏폼 드라마 수집 · hongguo

홍궈(Hongguo) 숏폼 드라마 수집 프로젝트입니다. 기기 등록, 동영상 다운로드와 트랜스코딩, 다운로드한 드라마 폴더, 회차별 파일 및 로컬 재생 화면을 소개합니다.

## 주요 기능 및 결과

- **기기 등록**: 등록 응답에 포함된 기기 ID와 설치 ID 등의 정보를 표시합니다.
- **다운로드 및 변환 진행 상황**: 다운로드 수, 변환 완료 수, 대기 중·변환 중·실패한 작업 수를 확인할 수 있습니다.
- **드라마별 폴더 관리**: ‘드라마 제목 + ID’로 폴더를 구분하여 쉽게 찾고 관리할 수 있습니다.
- **회차별 동영상 저장**: 회차 순서대로 파일을 정리합니다. 스크린샷의 파일 이름 예시는 `001_1080p.mp4`입니다.
- **재생 화면 예시**: 실사 드라마와 애니메이션의 로컬 재생 화면을 제공합니다.

## 스크린샷

### 1. 기기 등록 및 동영상 다운로드

기기 등록 응답과 다운로드 및 변환 작업의 진행 상황입니다. 캡처 당시 다운로드는 `127/222`, 변환 완료는 `118/222`, 대기 중인 작업은 `8`, 변환 중은 `1`, 실패는 `0`이었습니다.

![기기 등록 응답과 동영상 다운로드 및 변환 진행 상황](./device_register.png)

### 2. 다운로드한 드라마 폴더

각 드라마는 별도 폴더에 저장됩니다. 폴더 이름에는 드라마 제목과 해당 ID가 포함되어 있어 쉽게 구분하고 정리할 수 있습니다.

![다운로드한 드라마 폴더 목록](./videos_name.png)

### 3. 회차별 파일

드라마 폴더 안에는 동영상 파일이 회차 순서로 정렬되어 있습니다. 아래는 《持械入宋：第一季》의 예시로, `001_1080p.mp4`, `002_1080p.mp4` 등의 파일과 미리보기 이미지를 보여 줍니다.

![회차 순서로 정렬된 동영상 파일과 미리보기 이미지](./video_parts.jpg)
