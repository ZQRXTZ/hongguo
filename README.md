# 红果短剧采集 · hongguo

红果短剧采集项目，展示设备注册、视频下载与转码，以及下载后的短剧目录、分集文件和实际播放效果。

## 功能与效果概览

- **设备注册**：展示设备注册返回的设备与安装标识等信息。
- **下载与转码进度**：查看视频下载数量、转码完成数量，以及等待、转码中和失败任务数。
- **按短剧整理目录**：以「短剧名称 + ID」区分不同短剧，方便查找和管理。
- **按集保存视频**：分集文件按集数排列，截图中的文件命名示例为 `001_1080p.mp4`。
- **播放效果展示**：提供真人短剧与动画内容的本地播放截图。
